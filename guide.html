六個步驟，完成可以繳交的簡報

01 / SAVE

下載並保存提案

回到品牌創業教室，完成命名、客群、競爭分析、財務與CIS練習，點「下載我的提案 .txt」。請在電腦的下載項目確認檔案已存好。

02 / CHECK

檢查資料與數字

用文字編輯器打開TXT，核對品牌名稱、競爭來源、價格與成本。分清楚已知資料、提案設定和未驗證假設，不把預設數字當成實績。

03 / BUILD

選一條製作路徑

本頁直接製作：匯入TXT、編輯草稿、下載PPTX。
AI精修：上傳TXT到自己選用的工具，貼上完整提示詞。

04 / DESIGN

加入自己的設計圖

在PowerPoint中加入Logo、標準字、色票、包裝與社群應用圖。內建工具先產出文字版草稿，不會自動創作這些圖稿或查證競爭資訊。

05 / REHEARSE

檢查並演練

標題54級、正文與表格至少24級。逐頁確認公式、來源與圖片。15頁若需控制在8分鐘，可先以每頁約28秒、另留60秒換頁為排練起點。

06 / SUBMIT

匯出檔案再上傳

保存可編輯的PPTX，另匯出PDF，與TXT一起上傳數位學習平台。截止時間與頁數以老師最新公告為準，繳交後再確認三個檔案都能開啟。

3. 編輯逐頁內容

標題最多22字元；正文每行一個重點，建議3–5行，每行最多85字元。過長欄位會先節錄於正文，完整資料保留在講者備註供你重寫。請將資料來源留在相關頁面。

路徑 B｜複製提示詞，交給AI精修

  1. 開啟你選用且支援檔案上傳的AI工具，登入自己的帳號。
  2. 先上傳「咖啡品牌提案.txt」。上傳前確認你願意將其中內容交給該服務處理。
  3. 點下方「複製完整提示詞」，貼到對話框後送出。
  4. 如果工具支援產生檔案，要求提供可下載的PPTX；不支援時，將逐頁文字貼入PowerPoint，再自行排版。
  5. 下載後開啟檔案檢查。若只得到雲端路徑或無權限連結，請要求實際附件，或改用本頁直接製作工具。

交件前，請完成最後檢查

內容與設計

  • 品牌定位、MI／VI／BI與產品服務一致。
  • 自己的Logo與至少兩種應用圖已加入簡報。
  • 競爭來源、價格條件、日期與財務公式可核對。
  • 提案假設未被寫成訪談或試賣結果。
  • 標題54級，內文、表格與註記至少24級。
  • 完成8分鐘排練，並確認AI協助範圍已註記。

檔案與數位學習平台

  1. PowerPoint：保存PPTX，再使用「檔案 → 匯出／另存新檔 → PDF」。選單依軟體版本而異。
  2. 檔名：班級_學號_姓名_咖啡品牌期中提案。
  3. 上傳PPTX、PDF與原始TXT，不只交雲端連結。
  4. 確認上傳成功、檔案可開啟；繳交期限與要求以老師公告為準。
